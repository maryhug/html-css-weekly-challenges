## Páginas

| Archivo | Descripción |
|---|---|
| `index.html` | Página principal con sección "Sobre mí", proyectos y contacto |
| `pages/galeria.html` | Galería de fotografías con efectos de transición |
| `pages/mascotas.html` | Galería de mascotas |
| `pages/biografia.html` | Página de biografía personal |

## Conceptos aplicados

- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Diseño responsive con `viewport` y media queries
- Maquetación con **Flexbox** y **CSS Grid**
- Formulario de contacto con validaciones nativas del navegador
- Navegación interna con anclas (`#id`) y entre páginas

## Estructura del proyecto
```
html-css-portfolio/
├── index.html
├── css/
│ └── styles-index.css
├── assets/
└── pages/
├── galeria.html
├── mascotas.html
└── biografia.html
```

## Uso

Abre `index.html` directamente en el navegador o usa la extensión
**Live Server** de VS Code para verlo con recarga en vivo.
